{% comment %} The light/dark switch, shared by the site masthead and the teacher workspace. Two controls rather than one, matching the language switcher beside it, so the current theme is always legible on screen and a teacher never has to remember which state the button was in. Each carries `aria-pressed`, so the pair reads to a screen reader as a switch with a state rather than as two unrelated links. It is a form on purpose. JavaScript turns it into an instant, no-reload switch (theme-manager.js applies the theme, then posts here so the cookie is written with the server's own attributes), but with JavaScript switched off the form still works: it posts, the server stores the cookie, and the page comes back in the theme that was asked for.
