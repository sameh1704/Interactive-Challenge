{% load i18n %} {% comment %} Administration navigation. Two sources of links, and both are gated server-side: * the Django admin apps, from `available_apps`, which Django has already filtered by `has_module_permission` - so an app the viewer cannot reach is not rendered at all. That filtering is `core.admin.AdministratorAdminMixin` doing its job, and this template does not second-guess it. * the school's own pages - tournaments, hall of fame, reports, dashboard - which require a signed-in staff member and are reached with `{% url %} as`, so an item whose URL does not exist is omitted rather than rendered broken. Every `{% url ... as %}` below is the `as` form on purpose: it evaluates to empty when the name is unknown instead of raising, which is what keeps this template honest if a URL is ever renamed. {% endcomment %} {% url 'admin:index' as admin_index_url %}
