Extends Django's `admin/base.html` rather than replacing it, so every block it does not touch - the changelist, the forms, the filters, the pagination, the history, the delete confirmation - is Django's own, unmodified. That is the point: the administration interface keeps working exactly as it did, and only its appearance changes. Two stylesheets are loaded, in this order: core/css/site.css the project's design tokens and components, byte for byte the same file the dashboard, tournaments and reports use core/css/admin.css the small set of rules needed to sit *inside* Django's admin markup, which is generated and cannot be restructured here Django's own `admin/css/base.css` still loads underneath both.
