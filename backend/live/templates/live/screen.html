{% comment %} The classroom screen, served from both addresses a screen can be opened from. A screen is registered with its own URL: `/screen/?screen_id=AM-XXXXXX`, which is the address the Administrator reads out of the admin and types into the browser on the machine in the classroom. That URL, and that URL alone, is the screen's permanent address - it carries no competition, no round and no question, so nothing has to be re-typed when the next competition starts, and the server works out which round the screen belongs to from the classroom it is assigned to. The same display is also served at `/live/screen/` for anyone following a live link. Everything the screen needs to show is either in this markup or arrives over the WebSocket, because the screen is a display: it never chooses what to show, and it never knows the answer key. See live/static/live/js/screen.js.
