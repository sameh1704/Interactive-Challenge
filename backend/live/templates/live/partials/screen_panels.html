{% load i18n %} {% comment %} The panels of a live classroom screen, once, shared by both addresses a screen can be opened from. A screen is registered with its own URL (`/screen/?screen_id=AM-XXXXXX`, the one the Administrator copies from the admin), and the same display is also served at `/live/screen/`. Both pages run screen.js against exactly this markup, which is why it lives here rather than in either template: two copies would drift, and the symptom of that drift is a screen that shows the wrong thing in front of a classroom. Each panel is a state; screen.js shows exactly one. {% endcomment %}
